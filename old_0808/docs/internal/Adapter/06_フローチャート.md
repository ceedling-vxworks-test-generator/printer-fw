# Adapterレイヤ フローチャート

対象: `AdapterDispatcher::Dispatch(RIDataId id, const RIMValue& value)`

---

## 1. `Dispatch()` 内部処理フロー

```mermaid
flowchart TD
    Start([Dispatch呼び出し<br/>id, value]) --> Find[FindDataItem・・・<br/>product_からidで検索]

    Find --> FoundCheck{definition<br/>== nullptr?}

    FoundCheck -->|Yes<br/>未登録のRIDataId| ReturnFalse1[["return false<br/>(Storeへの投入なし)"]]

    FoundCheck -->|No| TypeCheck{value.type ==<br/>definition->rawValueType?}

    TypeCheck -->|No<br/>型不一致| ReturnFalse2[["return false<br/>(Storeへの投入なし)"]]

    TypeCheck -->|Yes| Normalize[definition->normalize<br/>value, nullptr を実行<br/>→ setValue]

    Normalize --> Build[RIMDataItem組み立て<br/>id / setValueType / setValue]

    Build --> Push[queue_.Push item]

    Push --> ReturnTrue[["return true"]]

    style ReturnFalse1 fill:#f8d7da,stroke:#c0392b
    style ReturnFalse2 fill:#f8d7da,stroke:#c0392b
    style ReturnTrue fill:#d4edda,stroke:#27ae60
```

## 2. Adapterレイヤ全体の入口(呼び出し元別)

```mermaid
flowchart TD
    subgraph API["API Layer (rim_api.cpp)"]
        SetBool["RIM_SetBool(id, int value)"]
        SetInt32["RIM_SetInt32(id, int32_t value)"]
        SetDouble["RIM_SetDouble(id, double value)"]
    end

    subgraph HW["ハードウェア起点(IHardwareAdapter実装 ※現状未導入)"]
        Poll["Poll()<br/>ハードウェアから生値を読む"]
        Lookup["FindDataItem(product, id)で<br/>rawValueTypeを取得し型付け"]
        Poll --> Lookup
    end

    SetBool --> CreateBool["RIMValueFactory::CreateBool"]
    SetInt32 --> CreateInt32["RIMValueFactory::CreateInt32"]
    SetDouble --> CreateDouble["RIMValueFactory::CreateDouble"]

    CreateBool --> Dispatch
    CreateInt32 --> Dispatch
    CreateDouble --> Dispatch
    Lookup --> Dispatch

    Dispatch{{"AdapterDispatcher::Dispatch(id, value)"}}

    Dispatch -->|true| Store[("StoreInputQueue<br/>(core/store)")]
    Dispatch -->|false| Error["呼び出し元でRI_INVALID_PARAMETER等として扱う"]
```

**ポイント**: `rim_api.cpp`側は「どの`RIM_SetXxx`が呼ばれたか」で型が確定しているため、`RIMValueFactory`で
直接型付けして渡す。一方ハードウェア起点の入力は生値の型が不定なため、`Dispatch()`を呼ぶ前に
`FindDataItem()`で`rawValueType`を引いて型付けする必要がある(このロジックはAdapterDispatcher側ではなく、
各`IHardwareAdapter`実装側に置く設計。`03_詳細設計書.md` 3章参照)。
