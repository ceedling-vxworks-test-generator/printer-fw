# Adapterレイヤ シーケンス図

対象: `AdapterDispatcher::Dispatch(RIDataId id, const RIMValue& value)`

`core/adapter/src/AdapterDispatcher.cpp`の実装に基づく。

---

## 1. 全体シーケンス(正常系・異常系まとめ)

```mermaid
sequenceDiagram
    autonumber

    box API Layer
    participant RimApi as rim_api.cpp<br/>(RIM_SetBool/SetInt32/SetDouble)
    end

    box Adapter Layer
    participant Dispatcher as AdapterDispatcher
    participant Product as ProductDefinition
    end

    box Store Layer
    participant Queue as StoreInputQueue
    end

    RimApi->>RimApi: RIMValueFactory::CreateXxx(value)<br/>で rawValueType 通りに型付け

    RimApi->>Dispatcher: Dispatch(id, value)

    Dispatcher->>Product: FindDataItem(product_, id)

    alt id が製品定義に存在しない
        Product-->>Dispatcher: nullptr
        Dispatcher-->>RimApi: false
        Note over RimApi: RI_INVALID_PARAMETER
    else id は存在する
        Product-->>Dispatcher: DataItemDefinition*

        alt value.type != definition->rawValueType
            Dispatcher-->>RimApi: false
            Note over RimApi: RI_INVALID_PARAMETER
        else 型が一致
            Dispatcher->>Dispatcher: definition->normalize(value, nullptr)
            Note over Dispatcher: rawValueType → setValueType へ変換

            Dispatcher->>Dispatcher: RIMDataItem組み立て<br/>(id, setValueType, 正規化後の値)

            Dispatcher->>Queue: Push(item)

            Dispatcher-->>RimApi: true
            Note over RimApi: RI_SUCCESS
        end
    end
```

---

## 2. 正常系(単独)

```mermaid
sequenceDiagram
    autonumber

    participant RimApi as rim_api.cpp
    participant Dispatcher as AdapterDispatcher
    participant Product as ProductDefinition
    participant Queue as StoreInputQueue

    RimApi->>Dispatcher: Dispatch(RI_DATA_UPPER_DOOR_OPEN, CreateBool(true))
    Dispatcher->>Product: FindDataItem(product_, id)
    Product-->>Dispatcher: kUpperDoorOpen (rawValueType=kBool)
    Dispatcher->>Dispatcher: value.type(kBool) == rawValueType(kBool) ✓
    Dispatcher->>Dispatcher: normalize = IdentityNormalize(value)
    Dispatcher->>Queue: Push({id, kBool, true})
    Dispatcher-->>RimApi: true
```

## 4. 異常系2: 型不一致

```mermaid
sequenceDiagram
    autonumber

    participant RimApi as rim_api.cpp
    participant Dispatcher as AdapterDispatcher
    participant Product as ProductDefinition

    Note over RimApi: 例: RIM_SetInt32をkBool型のRIDataIdへ誤って呼んだ場合

    RimApi->>Dispatcher: Dispatch(RI_DATA_UPPER_DOOR_OPEN, CreateInt32(1))
    Dispatcher->>Product: FindDataItem(product_, id)
    Product-->>Dispatcher: kUpperDoorOpen (rawValueType=kBool)
    Dispatcher->>Dispatcher: value.type(kInt32) != rawValueType(kBool) ✗
    Dispatcher-->>RimApi: false
    Note over RimApi: StoreInputQueueへのPushは発生しない<br/>(型タグ不一致のままStoreへ積まれることを防止)
```
