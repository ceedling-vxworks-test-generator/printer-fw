対象: `core/adapter` および直接の依存先。

## 2. 依存関係を含む全体図

```mermaid
classDiagram
    class AdapterDispatcher {
        -const ProductDefinition& product_
        -StoreInputQueue& queue_
        +Dispatch(id, value) bool
    }

    class ProductDefinition {
        +DataItemDefinition* dataItems
        +size_t dataItemCount
    }

    class DataItemDefinition {
        +RIDataId id
        +string_view name
        +ValueType rawValueType
        +ValueType setValueType
        +ValueType storeValueType
        +ValueType getValueType
        +NormalizeCallback normalize
        +StoreCallback store
        +DiffCallback diff
    }

    class RIMValue {
        +ValueType type
        +RIMValueStorage value
    }

    class RIMValueFactory {
        <<static>>
        +CreateBool(bool) RIMValue
        +CreateInt32(int32_t) RIMValue
        +CreateUInt32(uint32_t) RIMValue
        +CreateDouble(double) RIMValue
    }

    class RIMDataItem {
        +RIDataId id
        +ValueType valueType
        +RIMValue value
    }

    class StoreInputQueue {
        +Push(item: const RIMDataItem&) void
        +TryPop(item: RIMDataItem&) bool
        +WaitAndPop(item: RIMDataItem&) bool
    }

    AdapterDispatcher --> ProductDefinition : 参照(検索用)
    AdapterDispatcher ..> DataItemDefinition : FindDataItem()で取得
    AdapterDispatcher --> StoreInputQueue : 参照(Push先)
    AdapterDispatcher ..> RIMDataItem : 構築してPush
    DataItemDefinition --> RIMValue : normalize(RIMValue&, ctx) RIMValue
    RIMDataItem *-- RIMValue : 保持

    note for AdapterDispatcher "呼び出し元(rim_api.cpp)が\nRIMValueFactoryで型付けした\nRIMValueをDispatch()へ渡す"
```

## 3. 呼び出し元(参考: API Layer)

```mermaid
classDiagram
    class rim_api {
        <<free functions>>
        +RIM_SetBool(dataId, value) RIStatus
        +RIM_SetInt32(dataId, value) RIStatus
        +RIM_SetDouble(dataId, value) RIStatus
    }

    class RIManagerContext {
        +AdapterDispatcher dispatcher
        +StoreInputQueue storeQueue
    }

    rim_api ..> RIManagerContext : g_context経由でアクセス
    RIManagerContext *-- AdapterDispatcher
    RIManagerContext *-- StoreInputQueue
    rim_api ..> RIMValueFactory : 型付きRIMValueを組み立てる
```
