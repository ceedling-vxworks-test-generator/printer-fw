## 依存の向き(要点)

- `RawDataInput`(framework) は **抽象IFのみ**に依存:
  `IRuleResolver` / `IRule` / `IInputClassifier` / `ICentralInputPort`。
- 具象(機種可変)は devices 側: `PrinterADataProfile` が Resolver+Classifier を実装する。
  Rule実体は `PrinterADataProfile` のメンバではなく、`PrinterADataProfile.cpp` の`kTable`(id→Rule/Kind
  対応表)が状態を持たない単一インスタンスとして共有参照する(SelectRule/Classifyはこのテーブルへの
  参照窓口)。
- 送出先の具象 `CentralInputPort`(L2) は framework だが、Adapter は `ICentralInputPort` 抽象越しに使う
  → **Adapter 単体テストではモックに差し替え可能**。
